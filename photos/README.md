# Photos go here

Drop `.jpg`, `.jpeg`, `.png` or `.webp` images in this folder, then run
`python3 build.py` again. They'll rotate in the photo card and set the
blurred backdrop for the whole screen.

Tips:
- Landscape works best; portrait is fine too (the card crops to fill).
- File names become captions — `bierstadt-yosemite.jpg` shows as
  "Bierstadt yosemite", so name them nicely.
- Family photos, or public-domain paintings (Wikimedia Commons is a
  goldmine) while you curate.
